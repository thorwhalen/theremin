theremin.script_utils¶

Utility functions for running the theremin scripts.

This module focuses on fast CLI startup by deferring all heavy imports (cv2, mediapipe, pyo, theremin.audio, etc.) until they are actually needed (lazy import pattern). Only lightweight stdlib / small packages are imported at module import time so theremin -h remains responsive.

theremin.script_utils.run_theremin(*, video_features='many_video_features', pipeline=None, knobs=None, synth=None, log_video_features=None, log_knobs=None, record_to_file='theremin_recording.wav', window_name='Hand Gesture Recognition with Theremin', draw_on_screen=None, only_keep_new_freqs=True, freq_trans_override='__USE_DEFAULT__')¶

Run the realtime theremin loop.

Lazy-loads heavy dependencies (cv2, mediapipe, pyo, pipelines) only if actually executing the loop (i.e. not when just requesting CLI help). Handles:

  • Resolving named registry entries (video features, knobs/pipelines, synth)

  • Video capture + hand feature extraction

  • Mapping features to audio parameters (knobs)

  • Optional logging & drawing

  • Synth control & (optionally) recording, filtering unchanged freqs

Parameters:

  • pipeline (str | None) – Pre-configured pipeline name or ‘list’ to show available

  • video_features (str | None) – Feature extraction function or ‘list’ to show available

  • knobs (str | None) – Audio parameter mapping function or ‘list’ to show available

  • synth (str | None) – Synthesizer function or ‘list’ to show available

  • log_video_features (bool) – Enable logging of extracted video features

  • log_knobs (bool) – Enable logging of audio parameters

  • record_to_file (str) – Filename for audio recording (default: theremin_recording.wav)

  • no_recording (bool) – Disable audio recording

  • window_name (str) – Title for the video display window

  • scale (str | None) – Musical scale for frequency snapping or ‘list’ to show available scales
